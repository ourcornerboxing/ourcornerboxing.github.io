classes

fundamentals - (take this first if you're new to boxing)

In each class we will focus on a particular aspect of core boxing skills. We will introduce stance, punching, footwork, and basic combinations. Beginners should start here, and more experienced boxers should use this class to improve smaller details of their form. A strong foundation in these skills is critical for everything else.



conditioning

This class is the one to take if you want a workout above all else. Conditioning for boxing is extremely demanding and uses muscles across the whole body. This class will help push your cardio and strength to new levels, with bag rounds emphasizing volume of punches and longer combos. You will always be able to pace yourself and push to the level that feels right for you.



technique

This class assumes a familiarity with the basics. You should feel comfortable moving and punching in your fight stance. In this class we will work on the applications of those skills in the sport of boxing. Working angles and distance, changing levels, and the strategy of offense and defense will be the focus here. Anyone is welcome but it might be confusing if you are still figuring out the body mechanics of punching and moving.
